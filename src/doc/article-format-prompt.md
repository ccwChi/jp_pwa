# 給 AI 的轉換提示詞（文學文章 → 可放進 App 的格式）

把下面這段提示詞，加上你要轉換的原文段落，一起貼給 AI（ChatGPT、Claude 網頁版都可以）。
一次貼一章／一個段落即可，不用整部貼，避免 AI 漏字或偷懶跳過。

---

你是日文教材編輯。請把我貼的日文原文，轉換成以下 JS 格式，規則如下：

1. 把整段文字拆成一句一句（以「。」「！」「？」為斷句依據，但對話的「」要保持完整不要被切開）
2. 每一句輸出成 `{ jp: "...", zh: "..." }`：
   - `jp`：日文原文，把**原文本來就有標注音的漢字**改成 `漢字[かんじ]` 這種格式（把假名讀音移進方括號），例如原文「私わたし」要轉成「私[わたし]」
   - 原文沒有標注音的漢字（代表是比較基礎、不需要特別標的字）就維持原樣，不要自己加注音上去
   - 保留原文的標點符號、對話的「」
   - `zh`：這句話的中文翻譯，語意通順、符合中文語感即可，不用逐字直譯
3. 只要輸出一個 JS 陣列，不要其他說明文字，格式像這樣：

```js
[
  { jp: "これは、私[わたし]が小さいときに、村の茂平[もへい]というおじいさんからきいたお話です。", zh: "這是我小時候，從村裡一位叫茂平的老爺爺那裡聽來的故事。" },
  { jp: "その中山[なかやま]から、少しはなれた山の中に、「ごん狐[ぎつね]」という狐がいました。", zh: "從那個中山，稍微遠一點的山裡，住著一隻叫「阿權狐狸」的狐狸。" }
]
```

## 轉出來之後怎麼放進 App

文章資料放在 `src/lib/articles/` 資料夾，一個檔案可以放一篇文章，也可以放同一部作品的所有章節（看你想怎麼分）。

**新增一部作品的新章節**（例如繼續寫《ごん狐》第二章）：
1. 打開 `src/lib/articles/gon-gitsune.js`（同一部作品的章節放同一個檔案）
2. 在陣列裡新增一個章節物件，`seriesId`/`seriesTitle` 跟第一章一樣，`partIndex` 遞增（2、3、4…），`partTitle` 照原文的章節標示（二、三、四…）
3. `sentences` 欄位直接貼上 AI 產出的陣列
4. `vocab`、`grammar`、`quiz` 這三個欄位可以先給空陣列 `[]`，之後想補再補，不是必填

**新增一篇全新的文章/作品**：
1. 在 `src/lib/articles/` 底下新增一個檔案（檔名用這篇文章的 id，例如 `hashire-merosu.js`）
2. 內容格式參考 `jikoshoukai.js`（單篇文章）或 `gon-gitsune.js`（多章節作品）
3. 打開 `src/lib/articles/index.js`，照現有的樣子多加一行 import，並加進 `articles` 陣列裡

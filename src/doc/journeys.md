# 小說闖關與自由接續的學習路線

首頁以「今天完成下一關」為入口，優先續接最近尚未完成的路線；新使用者從《ごん狐》開始。沒有每日配額、缺席懲罰或登入連續天數。

## 內容

- `/journey/gon`：新美南吉《ごん狐》，原作六章切成 14 關，保留既有閱讀教材全部句子與譯文。
- `/journey/kumo`：芥川龍之介《蜘蛛の糸》，原作三章切成 10 關，保留青空文庫全文 14 個段落與原注音，另附本站中文教學譯文。
- 公版小說按順序解鎖，每關有目標、原文、翻譯、單字與句型、兩題附解析的練習、口頭重述。答錯可重試；兩題答對才通關。預估每關 5–12 分鐘，難度是教學估計，非官方 JLPT 分級。
- 完成全書後呈現讀畢狀態、全文回顧與選下一本入口；也可隨時展開全文自由閱讀，不計入通關。
- `/journey/konbini`：便利商店買晚餐，3 關。
- `/journey/rain-letter`：原創短篇《雨天的失物》，3 關；也會出現在閱讀書架。
- 每關包含內容、可揭露的翻譯、朗讀、文法提示、兩題理解題、口頭練習與故事接續。
- 情境與原創短篇維持任意選關；小說可複習已完成關卡。提示與重試不扣分。完成不等同熟練。
- `src/lib/journeys.js` 為路線內容來源。新增路線會透過 `generateStaticParams` 產生靜態頁。

## 新增公版小說

1. 確認作品與所用版本可再利用，保存來源、作者、底本及輸入校對署名。公版原作不代表任意現代譯本也可使用；中文教學譯文需另行撰寫或取得授權。
2. 將原文依原作章節放成 `chapters[].sentences`，每項具 `jp` 與 `zh`。來源不含全部漢字注音時，勿宣稱全文全注音。
3. 在 `src/lib/stories/` 建立教材，以 `buildStory` 組裝。`lessons` 按閱讀順序指定穩定 `id`、零起算 `chapter`、不含尾端的 `end`。每關由該章前一關終點接續，不能重排章節。不要用摘要取代任何原文段落。
4. 每關手寫 `title`、`goal`、`tips`、`questions`、`say`、`model`；理解題須能由本關讀到的內容回答，語言題須對應本關用法。不要把角色推測當成敘述者確認的事實。
5. 將路線加入 `src/lib/journeys.js`。需要閱讀書架入口時，參照 `reading/articles/data/kumo.js`，從同一份教材衍生文章，避免複製全文。
6. 執行驗證與建置。`buildStory` 拒絕越界與漏段；驗證腳本另比對這兩本書的完整順序。已上線的關卡 ID 應保持穩定，避免既有完成紀錄失效。

兩本作品的 UTF-8 來源快照為 `resources/gon-source.html` 與 `resources/kumo-source.html`（2026-10-01 取自上述青空文庫網址）。`node scripts/extract-kumo.mjs` 可重建《蜘蛛の糸》的原文 JSON。只轉換 ruby 標記與「犍」外字，不改寫正文；略去章號與文末寫作日期，原始署名與書目保留在來源檔及介面。《ごん狐》同步修正既有教材的 13 處轉錄差異；驗證會去除注音後，逐字比對兩本書的全文與來源快照。

## 進度與題目

- `nj_journeys` 保存目前關卡、步驟、答案、選項順序、提示狀態及已完成關卡。
- `nj_question_attempts` 保存嘗試次數、錯誤次數及最近是否答錯。一般練習可只抽取尚待重試的題庫題目。
- 閱讀及路線的紀錄使用各自前綴，重試入口在原內容中；一般練習不混入這些情境題。
- 資料保存在當前瀏覽器，既有「匯出全部資料」會包含上述資料。
- 文法的閱讀標記為手動「已看過」，不再因作答而自動標記。
- 選項打亂會同步重排答案與解析；不完整的題庫答案不會進入一般練習。

## 驗證

執行 `node scripts/verify-journeys.mjs` 驗證答案與解析對應、內容連結、24 個小說關卡、全文覆蓋與順序、逐關進度、閱讀題及儲存紀錄。

執行 `npm run lint`、`npm run build`、`npm run build:pages` 驗證程式及靜態匯出。

語音使用瀏覽器日文語音，沒有自動口說評分。後續內容仍須逐篇校對；本次修正已發現的教材錯誤，不代表既有整份題庫已完成語言審校。

瀏覽器流程驗證：啟動本機伺服器後，執行 `node scripts/verify-story-browser.mjs`（需 Playwright；可用 `PLAYWRIGHT_MODULE` 指向已安裝模組，`STORY_BASE_URL` 指定測試網址）。使用隔離瀏覽器測試 24 關、答錯重試、刷新續關、首頁接續、解鎖、全文回顧與手機寬度。此測試不操作日常瀏覽器資料。

仍需實機驗證：手機日文語音可用性、備份匯入後續關。

# 自由接續的學習路線

首頁提供「接著上次」、情境與原創短篇路線，以及原本的自由瀏覽書架。沒有每日配額、缺席懲罰或登入連續天數。

## 內容

- `/journey/konbini`：便利商店買晚餐，3 關。
- `/journey/rain-letter`：原創短篇《雨天的失物》，3 關；也會出現在閱讀書架。
- 每關包含內容、可揭露的翻譯、朗讀、文法提示、兩題理解題、口頭練習與故事接續。
- 任意選關，答對理解題後可完成；提示與重試不扣分。完成不等同熟練。
- `src/lib/journeys.js` 為路線內容來源。新增路線會透過 `generateStaticParams` 產生靜態頁。

## 進度與題目

- `nj_journeys` 保存目前關卡、步驟、答案、選項順序、提示狀態及已完成關卡。
- `nj_question_attempts` 保存嘗試次數、錯誤次數及最近是否答錯。一般練習可只抽取尚待重試的題庫題目。
- 閱讀及路線的紀錄使用各自前綴，重試入口在原內容中；一般練習不混入這些情境題。
- 資料保存在當前瀏覽器，既有「匯出全部資料」會包含上述資料。
- 文法的閱讀標記為手動「已看過」，不再因作答而自動標記。
- 選項打亂會同步重排答案與解析；不完整的題庫答案不會进入一般練習。

## 驗證

執行 `node scripts/verify-journeys.mjs` 驗證答案與解析對應、內容連結、閱讀題及儲存紀錄。

執行 `npm run lint`、`npm run build`、`npm run build:pages` 驗證程式及靜態匯出。

語音使用瀏覽器日文語音，沒有自動口說評分。後續內容仍須逐篇校對；本次修正已發現的教材錯誤，不代表既有整份題庫已完成語言審校。

仍需實機驗證：手機排版、日文語音可用性、點擊答題與重新整理續關、備份匯入後續關。
